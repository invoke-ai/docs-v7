Customizing the Image Map

Dieser Inhalt ist noch nicht in deiner Sprache verfügbar.

Adding custom tags

Section titled “Adding custom tags”

The default labeling vocabulary contains about 1200 terms that are frequently used to tag photographic images. To add additional custom terms, click on the Settings icon. You can then add up to 500 supplementary terms that will be applied to clusters and individual images. It may take up to a minute for tags to update after this operation.

Changing the cluster strength

Section titled “Changing the cluster strength”

The clustering algorithm uses a cluster strength coefficient to control the size and number of identified clusters. Higher coefficients lead to larger and fewer unclustered images. By default, InvokeAI tries to balance the coefficient so that not more than 10% of the images are unclustered. Usually this is good enough, but if you wish to adjust the cluster strength manually, you can do so by opening up the Image Map Settings dialogue, and adjusting the “Clustering Strength” parameter. Make small incremental changes. If the value is too high, most of your images will coalesce into a single monster cluster. If the value is too low, most of your images will be unclustered singletons. The Image Map displays these in gray.

Click “auto” to return to the default values.
