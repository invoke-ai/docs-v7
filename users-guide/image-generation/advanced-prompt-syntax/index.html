Advanced Prompt Syntax

Most prompts need nothing more than plain text, perhaps with a prompt template or a few dynamic prompt alternatives. This page covers the syntax for finer control: making parts of a prompt count for more or less, blending prompts, and the advanced forms of dynamic prompts.

Attention weighting

Section titled “Attention weighting”

Attention weighting makes parts of the prompt count for more or less than the rest. It uses Compel syntax, which applies to SD 1.5, SD 2.x and SDXL. Newer model families, including FLUX, Z-Image, CogView4 and Qwen Image, do not use it, and the symbols are passed to the model as ordinary text.

Compatibility note

If a weighted prompt seems to be ignored, check which model you are using. The syntax in this section only affects SD 1.5, SD 2.x and SDXL. The prompt field colors weights, groups and embeddings only while one of those models is selected; with any other model, or none, they appear as plain text.

trees+ / fog-Increase or decrease a single word
(golden hour light)+Weight a phrase
(cinematic lighting)1.25Use an exact numeric weight

Weighting with + and -

Section titled “Weighting with + and -”

Append + to increase influence, or - to reduce it.

  • Single words can be weighted directly. Wrap phrases of several words in parentheses.
  • Each additional + or - compounds, in steps of roughly 10%.
  • One or two steps is usually enough. Extreme weighting can overpower the rest of the prompt.

Numeric weights

Section titled “Numeric weights”

Use numeric weights when you want precise control instead of repeated plus or minus markers.

1 is neutral, values above 1 increase emphasis, and values between 0 and 1 reduce it. Wrap the weighted phrase in parentheses.

Groups can be nested, and the weights combine. In (portrait with (blue eyes)1.3)1.1, the outer group strengthens the whole phrase, and blue eyes gets even more emphasis.

Adjusting weights with the keyboard

Section titled “Adjusting weights with the keyboard”

In a prompt field, select text and press Ctrl+Up or Ctrl+Down to raise or lower its attention. With no selection, the shortcut targets the word at the cursor. Selecting a group’s parentheses or weight targets its contents. The shortcut works while an SD 1.5, SD 2.x or SDXL model is selected; with any other model the keys keep their usual text-editing behavior.

  • A selection inside a group changes only the selected words. A selection crossing a group boundary changes the selected words on both sides.
  • Symbolic weights move one + or - step. Numeric weights change by 0.1 of effective attention, including inherited group weights.
  • The numeric attention preference controls new weights; existing group weights keep their style.
  • Adjacent content with matching weights merges, and the adjusted content stays selected for the next keypress.
  • Inside prompt functions, the shortcut adjusts prompt arguments and preserves function parameters. Use Ctrl+Z to undo a weight change.

Blending with .blend()

Section titled “Blending with .blend()”

Use .blend() to mix the meaning of two or more prompts.

Provide one weight for each prompt. Keeping the weights near a total of 1 makes the result easier to reason about, and quoting each prompt is safest, especially when they contain commas.

Combining clauses with .and()

Section titled “Combining clauses with .and()”

Use .and() when you want separate prompt clauses encoded individually instead of as one long comma-separated sentence.

This can behave differently from red silk dress, studio portrait, soft rim light. If a normal prompt keeps collapsing ideas together, .and() is worth testing.

Comments

Section titled “Comments”

Dynamic prompts read three comment markers, and leave the comment out of the prompt:

MarkerLeaves out
#The rest of its line
//The rest of its line
/* … */Everything between the markers

There is no way to escape these markers. # turns any prompt into a dynamic prompt, so wall painted #ff0000 generates wall painted; // and /* */ only act in a prompt that is dynamic for other reasons, such as one containing {red|blue}. When a marker will drop text, a warning appears under the prompt with a Turn off dynamic prompts button.

To keep these characters as ordinary text, turn dynamic prompts off: switch off Use dynamic prompts at the top of the Dynamic popover. The prompt is then used exactly as typed, with braces, __wildcards__ and comment markers left in. The setting belongs to the project, and Dynamic reads Off while it is off.
