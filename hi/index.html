Invoke V7 Available Now!

AI image generation for creatives

Invoke is a free, open-source creative engine that runs on your own hardware. Generate images and video, compose them on a layered canvas and build node workflows with the latest open models, all in one workbench.
Download InvokeRead the docs

Windows · macOS · Linux · Apache 2.0

Canvas

Paint exactly where it matters

Mask an area, describe what belongs there and accept the result to a layer. Inpainting, outpainting, regional prompts and control layers all work on one canvas.

Canvas introduction

Workflows

Wire up your own pipeline

Chain steps into a node graph and run it from a simple form. Add community node packs with the Custom Node Manager, or follow the ComfyUI migration guide to the nodes you already know.

Community

Built in the open

Invoke is free software under the Apache 2.0 license, made by contributors around the world. The hosted Invoke.ai platform has shut down since its founding team joined Adobe. The open-source project carries on, stewarded by long-time core maintainers Lincoln Stein (lstein) and Vic (Blessedcoolant).
