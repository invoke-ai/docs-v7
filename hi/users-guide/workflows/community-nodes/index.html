Community Nodes

यह कंटेंट अभी तक आपकी भाषा में उपलब्ध नहीं है।

Node packs add new nodes to the Workflow Editor. The packs below are written and maintained by members of the community.

Only install packs you trust

A node pack runs Python code on your machine with InvokeAI’s permissions. Invoke doesn’t review or guarantee community packs. Report problems with a pack to its author, on its repository.

Install a node pack

Section titled “Install a node pack”
  • Nodes manager
  • Git

  1. Open Nodes in the Launchpad, or Nodes Manager in the app menu. When multi-user mode is on, only administrators see it.

  2. Click Add Nodes.

  3. Paste the pack’s Git URL, which Copy Git URL on a card below puts on your clipboard, and click Install.

    InvokeAI clones the repository into your nodes directory and loads its nodes without a restart. Workflows the pack ships are added to your workflow library.

  4. If a Dependencies required notice appears, install the Python packages the pack’s README lists into InvokeAI’s environment, then restart InvokeAI.

  1. Open a terminal in the nodes folder of your InvokeAI root directory. The Add Nodes view of the Nodes manager shows its path under Nodes Directory; the custom_nodes_dir setting changes it.

  2. Clone the pack:

    To update it, run git pull in the pack’s folder and restart InvokeAI.

  3. Click Reload in the Nodes manager, or restart InvokeAI.

You can also download a pack’s source as a ZIP and extract it into its own folder in nodes. InvokeAI loads a folder only when it has an __init__.py at its top level.

The Custom Node Manager page covers browsing, reloading and uninstalling packs. A workflow that uses community nodes loads like any other: import its .json file into the workflow library.

    by dwringer

    Compose images and masks, with Clipseg text masks, color separations, noise and wrapping offsets.

    • Compositing & grids
    • Masks & backgrounds
    Repository: Image and Mask Composition Pack
    Details: Image and Mask Composition Pack

    The image and latent offsets wrap around, so they can be used with seamless tiling to progressively generate centered on different parts of a seamless image.

    Git URL: https://github.com/dwringer/composition-nodes.git

    Nodes

    • 2D Noise Image: Creates an image of 2D noise approximating the desired characteristics.
    • Add Noise (Flux): Adds noise to a FLUX latents tensor using the appropriate ratio given the denoising schedule timestep.
    • Clipseg Mask Hierarchy: Creates a segmentation hierarchy of mutually exclusive masks from Clipseg text prompts.
    • CMYK Color Separation: Gets color images from a base color and two others that subtractively mix to obtain it.
    • CMYK Merge: Merges subtractive color channels (CMYK and alpha).
    • CMYK Split: Splits an image into subtractive color channels (CMYK and alpha).
    • Flatten Histogram (Grayscale): Scales the values of an L-mode image to the full range 0–255 in equal proportions.
    • Frequency Spectrum Match Latents: Generates latent noise with the frequency spectrum of target latents, masked by a mask image.
    • Image Quantize (Kohonen map): Quantizes the pixel values of an image with a Kohonen self-organizing map.
    • Image Search to Mask (Clipseg): Generates an image mask from an image prompt with the Clipseg model.
    • Latent Quantize (Kohonen map): Quantizes the values of a latents tensor with a self-organizing map.
    • Noise (Spectral characteristics): Creates a latents tensor of 2D noise channels approximating the desired characteristics.
    • Offset Image: Offsets an image by a percentage or pixel amount, wrapping it around.
    • Offset Latents: Offsets a latents tensor by a percentage of its height and width, wrapping it around.
    • RGB Merge: Merges RGB color channels and alpha.
    • RGB Split: Splits an image into RGB color channels and alpha.
    • Rotate/Flip Image: Rotates an image by an angle in degrees clockwise, or flips it.
    • Shadows/Highlights/Midtones: Extracts shadows, midtones and highlights masks from an image.
    • Text Mask: Renders a text mask in 2D from a given font.
    • Text to Mask (Clipseg): Generates an image mask from a text prompt with the Clipseg model.
    • Text to Mask Advanced (Clipseg): Generates image masks from several text prompts with the Clipseg model.
